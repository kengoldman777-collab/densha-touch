# でんしゃタッチ
スマホを横にして、画面をタッチするだけで遊ぶ幼児向け電車ゲーム。

## 遊ぶ
https://kengoldman777-collab.github.io/densha-touch/

- 画面全体に大きな線路と踏切を表示。電車の選択画面・残り秒数なし。
- タッチごとに4種類の電車からランダムで出発。下の線路は右へ進み、最後尾が見切れたら上の右側から左向きに戻る。上の左端を抜けたら下の左側へ戻る周回。
- まち・たんぼ・うみ・ゆきやまを30秒ごとに循環。
- 車は遮断機より手前で待機。すでに渡っている車を通してから遮断機を閉じ、電車を通す。
- 最初のタッチでオリジナルの穏やかなBGMが開始。音OFF・一時停止に対応。
- 「おおきく」で対応ブラウザの全画面表示。非対応端末でも横持ちで画面いっぱいに遊べる。

## 開発
`npm start` → http://localhost:4173 / `npm test` → 9件のゲームロジック検証。
配信物はdocs/。背景・先頭車両は内蔵image_genで生成した画像、BGMはWeb Audioのオリジナル短旋律。公式素材・外部音源は使っていません。
ブラウザ検証はPlaywrightを用意し `node tools/check-browser.cjs`。PLAYWRIGHT_PATHでモジュールパス、GAME_URLで公開先を指定可能。

## 検証範囲
667×375 / 844×390横画面、390×844縦画面、1280×900をEdgeで検証。全面描画、タッチ、BGMのAudioContext稼働と発音予約、停止、消音、回転、選択抑制、スクロールなし、JSエラーなしを確認。スマホ実機と音の聴感、iOSの全画面APIは未確認。Codex自己検証であり、独立レビューは未実施。
